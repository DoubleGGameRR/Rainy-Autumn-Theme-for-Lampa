# Rainy Autumn Theme for Lampa

A standalone autumn visual theme with animated rain, golden leaves and drifting mist.

## Features
- Subtle rain streaks and a soft wet-glass sheen
- Slowly falling yellow and golden leaves
- Low-contrast drifting autumn mist
- Rainy blue-grey palette with warm amber highlights
- Independent switches for theme, rain, leaves and mist
- Adjustable rain and leaf density
- No external images, fonts, libraries, tracking or network requests
- Overlay never captures remote-control input; reduced-motion support

## Install
Add this URL in Lampa:

```text
https://cdn.jsdelivr.net/gh/DoubleGGameRR/Rainy-Autumn-Theme-for-Lampa@main/rainy-autumn-theme.js
```

Settings are registered in the Interface section when supported by the installed Lampa build.

## Compatibility
Plain ES5-compatible JavaScript, CSS animations and inline DOM elements. Animation counts are intentionally modest for TV hardware.
