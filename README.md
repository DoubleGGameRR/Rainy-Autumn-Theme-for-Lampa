# Rainy Autumn Theme for Lampa

A standalone autumn visual theme with a stronger atmospheric background, subtle drifting mist behind the interface, fine rain and falling golden leaves.

## Features
- Richer blue-grey autumn background with muted amber light
- Slowly drifting fog layer placed behind Lampa content and posters
- Fine, translucent, slower rain streaks
- Falling yellow and golden leaves
- Independent switches for theme, rain, leaves and mist
- Adjustable rain and leaf density
- No external images, fonts, libraries, tracking or network requests
- Canvas rain and leaves scale with device pixel ratio (capped at 2)

## Install
Add this URL in Lampa:

```text
https://cdn.jsdelivr.net/gh/DoubleGGameRR/Rainy-Autumn-Theme-for-Lampa@main/rainy-autumn-theme.js
```

## Compatibility
Uses standard CSS animations, Canvas 2D and requestAnimationFrame. Animation counts and pixel ratio are capped for TV hardware.
